This is Mohammed's [Personal Website / Portfolio](#personal-website--portfolio) — **iM-Engr**

**iM-Engr** is a personal portfolio built around a dark, editorial-style interface with high-contrast serif typography and minimal UI. It also includes a deterministic, client-side conversational retrieval system that runs without AI or external services.

The design uses large italic serif typography for the primary messaging, with simpler sans-serif text for supporting information. The landing page also incorporates quotes from professors and industry leads through glassmorphic cards, while the academic section provides additional context around coursework through percentile rankings, uncurved scores, and class-average comparisons.

Navigation is kept intentionally simple with the **Work**, **Info**, and **Skills** sections, along with small interface elements such as the **AVAILABLE • ROLES & COLLABORATIONS** status indicator and modal-based content. The project section uses numbered entries with supporting metadata and subtle ↗ indicators rather than large project cards.

The same structure carries into the case studies. **FlowDraw**, for example, focuses on the engineering decisions behind the project, including gas optimization, state-machine invariants, and re-entrancy prevention. The **Online Retail Database System** follows the same approach by presenting the project as an engineering artifact rather than just a list of technologies.

The overall goal was to keep the interface minimal while still giving the portfolio enough technical and academic context to stand on its own.
